## 0. 一句話與設計意圖

> 運氣差到谷底時，社會會接住你一次；但自己選擇放掉的，不在其中。

本機制做三件事：
1. **讓前期運氣不好的玩家不放棄**：看見「老天還是有眷顧」。
2. **規則簡單到玩家看計分板就懂**：跌到線下，補到 5 點。
3. **不被策略利用**：自己選擇花掉的分數打上「自選低點」標記，不列入救濟。

## 1. 拍板定案之工程決策

| # | 決策 | 說明 |
|---|---|---|
| 1 | **審核與宣讀整合為單一彈窗** | 觸發救濟時直接跳出單一救濟彈窗，顯示說明與庇護內容，由主持人確認啟動，一次完成不跳二次彈窗。 |
| 2 | **閱讀確認勾選方可啟動** | 彈窗附帶「我已閱讀並確認」勾選框，勾選後「啟動救濟」按鈕才啟用，防止誤觸，確認後直接執行並關閉。 |
| 3 | **先不實作福慧交易所** | 本 repo 維持純計分、抽卡與氣象控制台定位，不包含交易所介面。 |

## 2. 時期劃分與救濟線

| 時期 | 範圍 | 救濟線 |
|---|---|---|
| **開局期** | 遊戲開始 → 第一次「氣象預報」發布之前 | **0**（歸零才救） |
| **預報後期** | 第一次「氣象預報」發布的那一刻 → 遊戲結束 | **3**（含 3，≤ 3 就救） |

- **動態界線**：界線自動由 `state.weatherEvents` 第一個事件的 `targetRound - 2` 決定（預設第 4 輪）。天時排程若調整，界線自動移動。
- **終局倒數優先**：若終局倒數早於第一次氣象預報開始，則終局倒數啟動那一刻視同界線，直接進入預報後期。
- **界線當下主動盤點（Sweep）**：
  第一次氣象預報發布時，系統自動盤點全場玩家，若符合「分數 ≤ 3、該項名額未用、無自選低點標記」，即彙整為盤點清單，跳出提示由主持人確認後統一執行救濟。

## 3. 觸發條件（被迫扣分）

在常態抽卡與調分時，以下四項同時成立即觸發救濟審核：
1. **被迫扣分**：卡片扣分、事件扣分、格子扣分（扣分後 `newVal < oldVal`）。
2. **跨過救濟線**：扣分後該項分數小於或等於當時救濟線（開局期為 0，預報後期為 3）。
3. **名額未用**：該玩家該項目（福報或智慧）的名額尚未用過。
4. **非自選低點**：該項目沒有「自選低點」標記。

---

## 4. 自選低點防策略利用機制

- **標記產生**：玩家在氣候調節換文明時，若將福報或智慧花費至 ≤ 3，系統在送出前彈出警告確認：「這次花費會讓你的〔XX〕降到 3 點以下。自己選擇的花費，不在社會救濟的範圍內。確定嗎？」確認後扣分，並為該項目打上 `selfSelectedLow = true` 標記。
- **標記效力**：標記存在期間，哪怕後續抽卡被迫扣分，亦不觸發救濟。
- **標記解除**：當該項目分數回升至 **≥ 4** 點時，系統自動清除標記，恢復未來救濟資格。
- **項目獨立**：標記只影響被標記之項目，不影響另一項。

---

## 5. 名額規則：每人、每項各一次

- 每位玩家的福報和智慧各自擁有 1 個名額，整局各自獨立使用。
- 單項符合只救單項並消耗該項名額；雙項同時符合則兩項皆補到 5 點並同時消耗雙名額。
- 計分卡在福報與智慧旁各顯示 1 個名額指示燈（亮綠為可用，暗灰為已用）。

## 6. 幸運庇護與倍率優先序

### 6.1 庇護規格
- **期間**：救濟輪次為第 N 輪，庇護期為第 **N+1** 與 **N+2** 輪（共兩輪有效，當輪不生效）。
- **倍率**：增加 ×1.5，扣減 ×0.5（文明永遠 1:1 不吃倍率）。
- **扣分捨入公式**：
  `Math.round(val * 1.5)`（加分）  
  `-Math.round(Math.abs(val) * 0.5)`（扣分）
- **換算對照**：
  - +1 → +2, +2 → +3, +3 → +5, +4 → +6
  - -1 → -1, -2 → -1, -3 → -2, -4 → -2
- **再次觸發順延**：若庇護期內又觸發另一項救濟，倍率不疊乘，庇護期順延至新救濟的 N+2 輪為止。

### 6.2 倍率優先序
1. **終局倒數**（×2 / ×2）：覆蓋一切，包含幸運庇護。
2. **幸運庇護**（×1.5 / ×0.5）：個人安全網，優先於天氣。
3. **氣象情報**（當輪鎖定天氣倍率）。
4. **無倍率**（×1 / ×1）。

## 7. 畫面與文案

### 7.1 整合式審核與救濟彈窗
- 將「主持人審核確認」與「閱讀說明」整合成單一彈窗，避免主持人操作中斷或出現二次連續跳窗。
- 彈窗顯示標題：`【社會救濟】`
- 彈窗內容：直接顯示宣讀說明文案或盤點對象與補點資訊。
- 單人單項正文：
  ```
  〇〇的〔福報〕跌到了 〇 點。
  社會救濟啟動，補到 5 點。

  接下來兩輪，〇〇受到庇護：
  好事加成，壞事減半。

  無常也會帶來轉運。
  ```
- 單人雙項正文：
  ```
  〇〇的福報與智慧同時見底。
  社會救濟啟動，兩項都補到 5 點。

  接下來兩輪，〇〇受到庇護：
  好事加成，壞事減半。

  無常也會帶來轉運。
  ```
- 多人合併（預報界線盤點）正文：
  ```
  第一次氣象預報發布，以下玩家達到救濟線：
  - 〇〇（福報）：補到 5 點
  - △△（智慧）：補到 5 點

  社會救濟啟動，各補到 5 點。
  接下來兩輪，他們受到庇護。
  ```
- 底部確認勾選：`[ ] 我已閱讀並確認`（不要求向全場宣讀完畢）。
- 操作按鈕：
  - `[稍後 / 取消]`：隨時可點擊，不執行救濟。
  - `[啟動救濟]`：預設為 disabled，勾選「我已閱讀並確認」後方可點擊；點擊後直接執行分數補至 5 點並套用 2 輪庇護，彈窗隨即關閉，不再彈出第二個全場公告彈窗。

### 7.3 計分板顯示
- 福報、智慧標籤旁顯示救濟名額圓點燈號（亮綠 / 灰暗）。
- 若存在自選低點標記，項目下方顯示淡色小字：「自選低點，不在救濟範圍」。
- 庇護中計分卡顯示：「庇護中，剩 〇 輪（加×1.5／扣×0.5）」。
